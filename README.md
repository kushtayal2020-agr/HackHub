# HackHub - Hackathon and Event Management Platform

Full Stack PBL project. HTML/CSS/JavaScript frontend, Node.js + Express backend, MySQL database.

## Run the backend locally
1. Run `schema.sql` in MySQL: `mysql -u root -p < schema.sql`
2. `cd backend`
3. Copy `.env.example` to `.env` and fill in your MySQL password and a JWT secret
4. `npm install`
5. `npm run dev`
6. Open http://localhost:5000/api/health
